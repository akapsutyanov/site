Установка

Как подключить за минуту

  1. Скачай файл кнопкой выше — это архив с инструкцией внутри, распаковывать не нужно.
  2. Открой Claude → настройки → раздел Skills / Навыки → загрузи файл seedance-clean.skill.
  3. Просто попроси промпт: «сделай промпт для Seedance: девушка идёт по ночной улице под дождём». Claude сам подхватит скилл и выдаст готовый промпт в блоке кода.
💡 Если раздела «Skills» в твоей версии нет — просто прикрепи файл в чат и напиши: «действуй по этой инструкции, напиши промпт для Seedance». Работает так же.

Хочешь снимать такое на заказ?

Скилл — это один инструмент. На обучении даю систему: от первой генерации до портфолио, упаковки и первых клиентов. Приходи на экскурсию — покажу платформу изнутри и работы учеников, разберу твою ситуацию. Ничего продавать не буду.
